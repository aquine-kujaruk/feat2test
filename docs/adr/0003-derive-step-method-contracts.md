# Derive Step Adapter method contracts

Step Name—not the complete TypeScript signature—is the stable method identity, and one Step Name cannot serve conflicting Step Roles. Methods require an explicit `void` or `Promise<void>` return annotation and receive no argument for a sole zero-input variant, one direct value for a sole one-input variant, or one generated `<StepName>Type` object for multiple inputs or variants. In a mixed zero/nonzero variant union, the zero-input call passes `{}` and its type is `Record<string, never>`. Gherkin values remain strings, while DocStrings and DataTables retain their structured forms. A missing or different return annotation is an unsupported Step shape. Changed inputs preserve the method body but make it Pending again; anonymous inputs remain valid with generic names and a warning.
